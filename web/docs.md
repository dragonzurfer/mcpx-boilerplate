# web/docs.md

## Purpose

Server-rendered HTML templates + static assets for Explore.

## Structure

- `templates/`: SSR templates (layout + page content, including Medium-inspired fonts/theme tokens, Marked + DOMPurify browser Markdown libraries, shared navigation, tools + courses + list-based practice library + practice detail with Figma-aligned split workspace spacing, desktop sticky editor behavior with page-level scrolling, and a localStorage-backed light/dark theme toggle for the problem workspace, account + admin pages and shared navigation with a mobile hamburger menu, plus post analytics, admin tools controls, admin course builder, admin user management (stage filtering + activity detail panes), and admin problem manager with form-based IO spec/constraints/examples/solutions plus dataset/testcase tooling; post detail uses a centered reader column while course detail uses a near full-width three-column reader layout (left module sidebar, center lesson content, right heading index/TOC) with a top promo slot, and practice detail includes a promo slot above the title).
- `templates/layout.html` injects CSS variables for theme (primary color + off-white) from site settings.
- Admin templates include inline helper copy for funnel and settings pages.
- Admin promos template includes field-level guidance and multi-variant support (add/remove variants).
- `assets/`: Tailwind browser runtime styles (`@tailwindcss/browser@4`) + vanilla JS app, including Medium-style site chrome, stronger centered reader/prose styling that overrides Tailwind resets for lists, Marked + DOMPurify client Markdown rendering with the existing handwritten parser retained as a fallback, One Tap prompts triggered by nav/CTA/login overlay buttons with a popup fallback when the inline chooser is suppressed, resilient loader visibility toggles that use class + native `hidden` + inline `display: none !important` fallback for home/courses/practice/tools/pricing, home-feed parsing that accepts common API envelope variants, parallel frontend bootstrap (`/api/me` hydration + page fetches), signed-in course explorer hydration (single expanded module + lesson lock handling), lesson heading TOC generation/scroll tracking for the course reader right rail, engagement event tracking for post/course/practice funnels, promo decisions across post/course/practice surfaces (including top promo slots on course/practice detail), Figma-aligned practice library list rendering with global search + solved markers + sticky stats, practice problem detail hydration with CodeMirror editor, markdown rendering for statement/editorial/examples/constraints (including `#`-style headings, paragraphs, ordered/unordered lists, blockquotes, links, inline code, fenced code language tags, Highlight.js code coloring, and official-solution cards in the editorial tab), immediate console reveal on Run/Submit click, disabled Run/Submit controls until polling resolves, row-selected submission history expansion with editor code restore, and rotating-label AI analysis CTAs (sparkle icon) that appear only for non-accepted verdicts (console header + expanded submission result cards); free practice-limit errors now open the pricing/paywall overlay, pricing-plan benefit/savings messaging, a full focus-path explorer in Career Copilot guided selection, and admin-users interactions for stage-filtered member search plus paginated event/promo activity inspection.
- Static legal pages: `privacy.html`, `terms.html`, etc.
- `tools.html` + `tool.html`: tools catalog and Career Copilot flow shell (hero + tag chips, dossier-style progress header, completion chips, recap cards after the initial plan, single active stage card for resume upload, ATS analysis, focus, subfocus, questions, mentor response, and chat + voice input, plus loading indicators for tool-list fetch, resume analysis, plan generation, chat response, and voice transcription; focus stage includes a hero + inline status chips + selection panel + all-path preview map; chat stage stacks the recap content and mentorship shell in a single column with dossier-specific card styling, live waveform feedback during voice input, and hidden usage-limit text; the mentor response stage is auto-completed and the UI jumps directly to chat once the plan is generated).
 - `admin_tools.html`: admin controls for tool gating + tracking.
