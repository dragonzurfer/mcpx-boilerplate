# web/docs.md

## Purpose

Server-rendered HTML templates + static assets for Explore.

## Structure

- `templates/`: SSR templates (layout + page content, including Medium-inspired fonts/theme tokens, Marked + DOMPurify browser Markdown libraries, shared navigation, tools + courses + list-based practice library + practice detail with Figma-aligned split workspace spacing, desktop sticky editor behavior with page-level scrolling, and a localStorage-backed light/dark theme toggle for the problem workspace, account + admin pages and shared navigation with a mobile hamburger menu, plus post analytics, admin tools controls, admin course builder, dedicated admin lesson editor tab/page for add/edit flows with live completed-line markdown preview, admin user management (stage filtering + activity detail panes), and admin problem manager with form-based IO spec/constraints/examples/solutions plus dataset/testcase tooling; post detail uses a centered reader column while course detail uses a near full-width three-column reader layout (left module sidebar, center lesson content, right heading index/TOC) with top promo + lesson share controls and URL-shareable module/lesson state, practice detail includes a promo slot above the title, and pricing uses a compact two-panel desktop layout with yearly-first emphasis and monthly/quarterly/yearly plan cards).
- `templates/layout.html` injects CSS variables for theme (primary color + off-white) from site settings and links the Explore `E` favicon asset.
- Admin templates include inline helper copy for funnel and settings pages.
- Admin promos template includes field-level guidance and multi-variant support (add/remove variants).
- `assets/`: Tailwind browser runtime styles (`@tailwindcss/browser@4`) + vanilla JS app, including Medium-style site chrome, stronger centered reader/prose styling that overrides Tailwind resets for lists, Marked + DOMPurify client Markdown rendering with the existing handwritten parser retained as a fallback, One Tap prompts triggered by nav/CTA/login overlay buttons with a popup fallback when the inline chooser is suppressed, a first-login phone-completion modal flow (`/api/auth/login` -> `phone_required` -> `/api/auth/phone-countries` selector -> `/api/auth/complete-phone`) so JWT session creation is blocked until phone capture succeeds, resilient loader visibility toggles that use class + native `hidden` + inline `display: none !important` fallback for home/courses/practice/tools/pricing, home-feed parsing that accepts common API envelope variants, parallel frontend bootstrap (`/api/me` hydration + page fetches), signed-in course explorer hydration with a modern accordion roadmap module list (clear selected/locked lesson states), robust module expand/collapse using stable string module keys, a single shared roadmap scroll rail across modules + lessons with leveled tree styling (no nested module scroll boxes), left-aligned lesson titles with word-based wrapping in the roadmap rail, deep-link URL syncing for selected course module/lesson (`?module=<id>&lesson=<slug>`), lesson-header share actions (copy + WhatsApp + social targets), lesson heading TOC generation/scroll tracking for the course reader right rail with top-level markdown headings included and relative nesting preserved, a mobile-first lesson reader stack (single-column, lesson-first ordering, tightened prose scales, and safer overflow for tables/code/long lines), admin lesson add/edit actions that open a dedicated lesson editor tab, completed-line markdown live-preview logic for lesson authoring, engagement event tracking for post/course/practice funnels, promo decisions across post/course/practice surfaces (including top promo slots on course/practice detail), Figma-aligned practice library list rendering with global search + solved markers + sticky stats, practice problem detail hydration with CodeMirror editor, markdown rendering for statement/editorial/examples/constraints (including `#`-style headings, paragraphs, ordered/unordered lists, blockquotes, links, inline code, fenced code language tags, Highlight.js code coloring, and official-solution cards in the editorial tab), immediate console reveal on Run/Submit click, disabled Run/Submit controls until polling resolves, row-selected submission history expansion with editor code restore, and rotating-label AI analysis CTAs (sparkle icon) that appear only for non-accepted verdicts (console header + expanded submission result cards); free practice-limit errors now open the pricing/paywall overlay, pricing-plan benefit/savings messaging, compact one-view pricing layout, yearly-first plan ordering, and subscribe-button loading states that stay active until Razorpay checkout is ready, plus admin-users interactions for stage-filtered member search and paginated event/promo activity inspection.
- Static legal pages: `privacy.html`, `terms.html`, etc.
- `tools.html` + `tool.html`: tools catalog and Career Copilot flow shell (hero + tag chips, dossier-style progress header, completion chips, recap cards after the initial plan, single active stage card for resume upload, ATS analysis, focus, subfocus, questions, mentor response, and chat + voice input, plus loading indicators for tool-list fetch, resume analysis, plan generation, chat response, and voice transcription; focus stage includes a hero + inline status chips + selection panel + all-path preview map; chat stage stacks the recap content and mentorship shell in a single column with dossier-specific card styling, live waveform feedback during voice input, and hidden usage-limit text; the mentor response stage is auto-completed and the UI jumps directly to chat once the plan is generated).
 - `admin_tools.html`: admin controls for tool gating + tracking.
