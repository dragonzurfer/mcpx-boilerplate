# web/assets/docs.md

## Purpose

Client-side behavior for Explore (landing, post reader, pricing, checkout).

## Files

- `app.js`: routing-aware UI logic, auth (GIS; FedCM disabled on localhost) with One Tap prompts triggered by nav/CTA/login overlay buttons plus a popup fallback when the inline chooser is suppressed, nav state toggling (login/admin links) plus mobile hamburger menu toggle, using locally cached user/entitlement to avoid UI flicker, and post-payment `/api/me` refresh to update cached entitlements. First-time auth now enforces phone capture: if `/api/auth/login` responds with `phone_required`, the client opens a blocking phone modal, fetches country/dial options from `/api/auth/phone-countries`, validates national number input (including India 10-digit client guard), and completes login only after `/api/auth/complete-phone` returns the app JWT. Bootstrap now runs page data requests in parallel with `/api/me` hydration, then re-renders auth-sensitive pages if identity state changes. Includes engagement tracking across post/course/practice funnels (post milestones + completion + promo/paywall, course open/lesson/time, practice open/run/submit/AI/time), promo rendering on post surfaces (inline/bottom/completion modal) plus course/practice top slots, Razorpay checkout, account + admin flows rendering, funnel UI normalization (snake/camel-case API fields), multi-variant promo editor UI, and admin form validation/error display (with auto-scroll to errors). Signed-in users load PUBLIC+TRIAL+PAID listings for newsletters/courses and search; tools catalog + Career Copilot flow (resume upload -> Gemini analysis -> focus -> subfocus -> questions -> mentor response -> chat + voice transcription) are wired to `/api/tools/*` for usage limits. Home, courses, practice lists, tools, and pricing loading now toggles both `hidden` class and native `hidden` attribute, plus an inline `display: none !important` fallback on hide, so loaders always clear even when utility class ordering is unfavorable; home parsing accepts multiple response shapes (`items`, `data.items`, `posts`, `data.posts`) before rendering cards. Practice library now renders list sections from `/api/problem-lists`, supports a Figma-aligned global search by problem name/tag/difficulty, marks solved problems in muted styling with a solved badge, and renders sticky solved stats (including solved/total by difficulty). Practice problem detail hydrates the statement/editorial tabs, boots CodeMirror with language templates, supports a localStorage-backed light/dark toggle (`practice_theme`) that also switches CodeMirror theme, submits runs/submits, polls for results, renders verdict + failed test detail (including a non-AC no-tests error state), keeps the console hidden on first load but reveals it immediately on Run/Submit click with pending status, keeps Run/Submit disabled until polling resolves, expands the editor when no result panel is visible, refreshes CodeMirror sizing after console toggles/theme changes, loads submission history, expands the selected submission inline directly under the clicked row, restores that submission's code in the editor, and drives rotating-label AI actions (sparkle icon) only when the verdict is not accepted (console header + expanded submission result cards). The client markdown renderer now prefers Marked + DOMPurify for GFM-quality sanitized HTML, adds safe external-link attributes after sanitization, and falls back to the local parser for `#` through `######` headings, paragraphs, unordered/ordered lists, blockquotes, horizontal rules, links, protected inline code, fenced-code language hints, Highlight.js coloring when available, inline LaTeX fallback text, and official-solution editorial cards from `problem.official_solutions`. Free practice usage limits (`RUN + SUBMIT` and AI analysis) now surface the subscription/paywall overlay as soon as the backend limit response is received. Course detail hydrates a signed-in-only three-rail reader (module sidebar as a modern accordion list, lesson content, and auto-generated right-side heading TOC, including top-level markdown headings with relative nesting), with per-lesson lock state, paywall modal triggers for locked paid lessons, sticky heading index scroll/highlight behavior, and a top promo card slot above lesson content. Pricing now renders a compact one-view desktop layout, yearly-first plan order, monthly/quarterly/yearly card variants with dynamic savings labels, and subscribe buttons that enter a loading state immediately on click and remain disabled until Razorpay checkout is ready or closed. After mentor generation, the flow jumps directly to the final chat stage (mentor response is auto-completed and rendered in the recap), skipping an intermediate page. Tool state (resume text, selections, mentor output, chat history) is cached in sessionStorage only when `?resume=1` is present; otherwise the tool starts fresh on each visit. Career Copilot animates stage transitions with Motion One, renders focus/subfocus/question options as card tiles, shows status chips for completed/active stages, and renders a full "all paths" focus map (every focus + subfocus combination) so users can preview or preselect the route before entering subfocus. The flow normalizes stale stored focus/subfocus pairs before rendering, injects the mentor response into the recap when the chat stage is active, and drives a live voice waveform plus transcribing loader during voice input. Chat stage uses a single-column dossier stack with recap content above the mentorship shell. Lucide icons are refreshed after dynamic UI updates; chat replies are markdown rendered client-side with a minimal sanitizer/renderer. Admin users UI now supports funnel-stage filtering, paginated list navigation, and detail-side paginated event/promo activity panels from `/api/admin/users/:id/activity`; admin tools UI manages tool gating + tracking; admin post analytics UI renders summary, funnel, trends, and promo tables; admin courses UI manages structured course metadata plus module/lesson CRUD + ordering; admin problems UI manages practice problem CRUD with form-based IO spec/constraints/examples/solutions, dataset/testcase creation, and a searchable problem-list assignment manager (create/edit/delete lists and add/remove ordered problems).
- `app.js` admin users stage-filter options normalize both `stage/enabled` and `Stage/Enabled` response keys from funnel stage APIs so dropdown options always render.
- `app.js` admin funnel config hydration now tolerates both snake_case and legacy PascalCase response keys, so `/api/admin/funnel/config` always populates form fields correctly.
- `styles.css`: Medium-inspired site chrome and typography on top of the Tailwind browser runtime (`@tailwindcss/browser@4`), including white/black/green navigation, compact card radius/shadow normalization, centered post/course reader shells, a near full-width three-rail course reader grid on desktop with a mobile-first single-column lesson-first stack, responsive markdown typography/spacing, and safe mobile overflow handling for long lines/tables/code blocks, a conversion-focused pricing layout (compact two-panel shell, yearly-first visual emphasis, and subscribe-button loading spinner states), Source Serif article prose with explicit list-marker overrides for Tailwind reset compatibility, paragraphs/lists/quotes/code/tables, plus tool-specific shells (cards, chips, dossier progress header, ATS analysis cards + score ring, mentor grids, focus selection hero/panel with inline status chips, all-path explorer cards/chips for guided selection, subfocus selection grid, dossier recap layout overrides, chat shell + composer styling, live voice waveform, hidden usage-limit text, and input treatments).
- `favicon-explore-e.svg`: brand favicon asset used by `layout.html` for browser tabs/bookmarks.
