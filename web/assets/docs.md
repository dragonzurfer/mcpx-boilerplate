# web/assets/docs.md

## Purpose

Client-side behavior for Explore (landing, post reader, pricing, checkout).

## Files

- `app.js`: routing-aware UI logic, auth (GIS; FedCM disabled on localhost) with One Tap prompts triggered by nav/CTA/login overlay buttons plus a popup fallback when the inline chooser is suppressed, nav state toggling (login/admin links) using locally cached user/entitlement to avoid UI flicker, and post-payment `/api/me` refresh to update cached entitlements. Bootstrap now runs page data requests in parallel with `/api/me` hydration, then re-renders auth-sensitive pages if identity state changes. Includes engagement tracking (incl. `post_complete`), promo rendering (inline/bottom/completion modal), Razorpay checkout, account + admin flows rendering, funnel UI normalization (snake/camel-case API fields), multi-variant promo editor UI, and admin form validation/error display (with auto-scroll to errors). Signed-in users load PUBLIC+TRIAL+PAID listings for newsletters/courses and search; tools catalog + Career Copilot flow (resume upload -> Gemini analysis -> focus -> subfocus -> questions -> mentor response -> chat + voice transcription) are wired to `/api/tools/*` for usage limits. Home, courses, tools, and pricing loading now toggles both `hidden` class and native `hidden` attribute, plus an inline `display: none !important` fallback on hide, so loaders always clear even when utility class ordering is unfavorable; home parsing accepts multiple response shapes (`items`, `data.items`, `posts`, `data.posts`) before rendering cards. Course detail now hydrates a signed-in-only module sidebar + lesson viewer with single-module expansion, per-lesson lock state, and paywall modal triggers for locked paid lessons. Pricing cards now include audience guidance (short sprint vs multi-month prep), full-access benefits, and computed yearly savings/strike-through value cues to nudge yearly conversion. After mentor generation, the flow now jumps directly to the final chat stage (mentor response is auto-completed and rendered in the recap), skipping an intermediate page. Tool state (resume text, selections, mentor output, chat history) is cached in sessionStorage only when `?resume=1` is present; otherwise the tool starts fresh on each visit. Career Copilot animates stage transitions with Motion One, renders focus/subfocus/question options as card tiles, shows status chips for completed/active stages, and now renders a full "all paths" focus map (every focus + subfocus combination) so users can preview or preselect the route before entering subfocus. The flow normalizes stale stored focus/subfocus pairs before rendering, injects the mentor response into the recap when the chat stage is active, and drives a live voice waveform plus transcribing loader during voice input. Chat stage uses a single-column dossier stack with recap content above the mentorship shell. Lucide icons are refreshed after dynamic UI updates; chat replies are markdown rendered client-side with a minimal sanitizer/renderer. Admin tools UI manages tool gating + tracking; admin post analytics UI renders summary, funnel, trends, and promo tables; admin courses UI manages structured course metadata plus module/lesson CRUD + ordering.
- `styles.css`: typography + markdown styles on top of the Tailwind browser runtime (`@tailwindcss/browser@4`), light theme background + off-white surface styling, plus tool-specific shells (cards, chips, dossier progress header, ATS analysis cards + score ring, mentor grids, focus selection hero/panel with inline status chips, all-path explorer cards/chips for guided selection, subfocus selection grid, dossier recap layout overrides, chat shell + composer styling, live voice waveform, hidden usage-limit text, and input treatments).
