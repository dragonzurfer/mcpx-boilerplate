# web/assets/docs.md

## Purpose

Client-side behavior for Explore (landing, post reader, pricing, checkout).

## Files

- `app.js`: routing-aware UI logic, auth (GIS; FedCM disabled on localhost), nav state toggling (login/admin links) using locally cached user/entitlement to avoid UI flicker, and post-payment `/api/me` refresh to update cached entitlements. Includes engagement tracking (incl. `post_complete`), promo rendering (inline/bottom/completion modal), Razorpay checkout, account + admin flows rendering, funnel UI normalization (snake/camel-case API fields), multi-variant promo editor UI, and admin form validation/error display (with auto-scroll to errors). Signed-in users load PUBLIC+TRIAL+PAID listings for newsletters/courses and search; tools catalog + Career Copilot flow (resume upload → Gemini analysis → focus → subfocus → questions → mentor response → chat + voice transcription) are wired to `/api/tools/*` for usage limits. After mentor generation, the flow now jumps directly to the final chat stage (mentor response is auto-completed and rendered in the recap), skipping an intermediate page. Tool state (resume text, selections, mentor output, chat history) is cached in sessionStorage only when `?resume=1` is present; otherwise the tool starts fresh on each visit. Career Copilot animates stage transitions with Motion One, renders focus/subfocus/question options as card tiles, shows status chips for completed/active stages, injects the mentor response into the recap when the chat stage is active, and drives a live voice waveform plus transcribing loader during voice input. Chat stage uses a single-column dossier stack with recap content above the mentorship shell. Lucide icons are refreshed after dynamic UI updates; chat replies are markdown rendered client-side with a minimal sanitizer/renderer. Admin tools UI manages tool gating + tracking; admin post analytics UI renders summary, funnel, trends, and promo tables.
- `styles.css`: typography + markdown styles on top of Tailwind CDN, light theme background + off-white surface styling, plus tool-specific shells (cards, chips, dossier progress header, ATS analysis cards + score ring, mentor grids, focus selection hero/panel with inline status chips, subfocus selection grid, dossier recap layout overrides, chat shell + composer styling, live voice waveform, hidden usage-limit text, and input treatments).
